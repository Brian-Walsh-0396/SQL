# SQL & Data Analysis Portfolio

Welcome to my SQL & Data Analysis portfolio. This repository documents my ongoing work as I build and demonstrate practical skills in **SQL, MySQL, data analysis, and data visualization**.

## 🚧 Work in Progress

This is an **actively developing project**. I am continuously adding queries, analysis, and projects as I expand my SQL and data analysis skills.

All SQL development and analysis is being completed in **Visual Studio Code (VS Code)**, connected to a **local MySQL server**.

## 🗄️ Dataset

The data used in this portfolio comes from the **MySQL Sample Database**, a practice dataset designed for learning and experimenting with MySQL.

Dataset source: [MySQL Sample Database – MySQLTutorial.org](https://www.mysqltutorial.org/getting-started-with-mysql/mysql-sample-database/?utm_source=chatgpt.com)

The database includes related business data covering areas such as:

* Customers
* Employees
* Offices
* Orders
* Order Details
* Products
* Payments
* Product Lines

## 🎯 What I'm Practicing

Projects and exercises in this repository focus on developing practical proficiency with:

* `SELECT` / `FROM`
* `WHERE`
* `JOIN`
* `ORDER BY`
* `GROUP BY`
* Aggregate functions
* Data filtering and segmentation
* Relational database analysis
* Business-oriented questions and insights
* SQL-driven data preparation for visualization

As the portfolio develops, I plan to incorporate more advanced SQL techniques and connect analysis to visualization tools such as **Tableau**.

## 📈 Goal

The goal of this repository is to demonstrate not only that I can write SQL, but that I can use data to **answer business questions, identify trends, and communicate actionable insights**.

> **This portfolio is a work in progress and will continue to evolve as I build my data analysis capabilities.**
